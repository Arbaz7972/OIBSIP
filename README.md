# ✈️ Travel Landing Page — Wanderly

## 📌 About the Project
Wanderly is a responsive travel landing page created as part of the Oasis Infobyte Web Development Internship. It showcases beautiful travel destinations and encourages users to explore the world.

## 🎯 Features
- Responsive navigation bar
- Attractive hero section with a call-to-action button
- Popular destinations: Bali, Paris, Switzerland, and Santorini
- Destination cards with background images
- Travel benefits section
- Footer with contact information
- Smooth scrolling navigation
- Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## 🚀 How to Run
1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Use Live Server for a better development experience.
